偽代碼
count ← 0
設 k 由 0 至 N-1
    如果 the_list[k] > bound 則
        count ← count + 1
輸出 count
Python
count = 0
N = len(the_list)
for k in range(0, N):
    if the_list[k] > bound:
        count = count + 1
print(count)

找出最大或最小的值

📘 解說
先用一個變量暫存列表第一個項目，再逐一與其餘項目比較；發現更大（或更小）的值，便更新該變量。
🧠 知識重點
Python
largest = the_list[0]
N = len(the_list)
for i in range(1, N):
    if the_list[i] > largest:
        largest = the_list[i]
print(largest)
🤔 試想想：為何迴圈由索引 1 開始？因為索引 0 已作為起始值，無需與自己比較。
要記錄「誰」最低分，可另設 lowest_no 儲存索引，學號 = 索引 + 1。

C

檢查列表中的值是否按次序排列

📘 解說
用旗標（Flag）記錄檢查結果。先假設 sorted_list = True，逐對比較相鄰項目；只要有一對次序錯誤，就設為 False。旗標只有「是／否」，應用布爾數據類型。
🧠 知識重點
Python
sorted_list = True
N = len(the_list)
for k in range(0, N-1):
    if the_list[k] > the_list[k+1]:
        sorted_list = False
print(sorted_list)
⚠️ 迴圈只到 N-2（range(0, N-1)），因為要比較 k 與 k+1，否則會超出範圍。

加入或刪除列表中的項目

📘 解說
刪除索引 P：P 之後的項目逐一向前移一格（由前至後處理）。
加入到索引 P：先加長列表，再把項目逐一向後移一格（由尾至前處理），最後放入新項目。
🧠 知識重點
刪除
N = len(the_list)
for k in range(P, N-1):
    the_list[k] = the_list[k+1]
N = N - 1
加入
the_list = the_list + [0]
N = len(the_list)
for k in range(N-1, P, -1):
    the_list[k] = the_list[k-1]
the_list[P] = new_data
💡 加入時若由前往後搬，後面的資料會被覆蓋，所以必須由尾開始。

調動列表中的項目

📘 解說
把索引 P 的項目調到第一位：先用 temp 暫存它，P 前的項目逐一向後移，最後把 temp 放到索引 0。
🧠 知識重點
Python
temp = the_list[P]
for k in range(P, 0, -1):
    the_list[k] = the_list[k-1]
the_list[0] = temp
