2.1 應用控制結構

順序 · 選擇 · 迭代（循環）· 嵌套循環

① 順序
  • 指令從上到下逐行執行。
② 選擇 · 嵌套選擇
  • 允許程式使用布爾邏輯做出決定，使用 if、elif 和 else。
  • 嵌套選擇：將一個 if 語句放在另一個 if 語句內，以檢查特定的子條件。
③ 迭代（循環）
  • for 循環：適合重複次數已知時使用（確定性迭代）。
  • while 循環：一種預先測試循環，只要條件為 True 就會運行，適合重複次數未知時使用。

for 循環（固定範圍）

提示：試試 range(1, 1)、range(0, 5)

while 循環（預先測試）

提示：試試 0 或負數，看看循環體會否執行

④ 嵌套循環
  • 一個循環在另一個循環內，對於處理二維陣列（網格 / 表格）至關重要。
  • 外層循環通常控制行（i）；內層循環通常控制列（j）。
  • 外層循環每完成一次迭代，內層循環就完成一個完整的週期。

2.2 二維陣列

行 = row（i，由上數下）· 列 = column（j，由左數右）· 索引都由 0 開始

① 攤位地圖 F：讀取與賦值
  • 要提取（讀取）陣列中的資訊，只需引用陣列名稱和特定索引：偽代碼 Variable ← ArrayName[Row][Column]；Python Variable = ArrayName[Row][Column]。
  • 要賦值陣列中的一個元素：偽代碼 F[3][2] ← 29；Python F[3][2] = 29。

2.3 計數、累加及交換算法

計數器加常數 · 總數加實際數據值 · 交換要先保護數據

① 計數 與 累加（求和）
  • 計數：滿足特定條件發生的次數。將計數器初始化為 0；在循環內部，當滿足條件時加上一個常數值（通常是 1）。
  • 累加：計算運行總和。將總數初始化為 0；在循環內部，加上實際數據值（例如價格、分數）。
最多 8 個整數，用逗號分隔

🔢 計數

count = count + 1
條件成立才加，每次加常數 1

➕ 累加

total = total + item
每次都加，加的是實際數據值

計數：計算 > 50 的項目

累加：計算所有項目的總和

② 交換
  • 在兩個變量（例如 A 和 B）之間交換值。
  • 暫存變量方法：防止數據丟失的標準、安全方法。
  • 數學方法：使用加法和減法進行交換而不需要第三個變量，但有算術溢出的風險。

③ 數學方法的風險：算術溢出

假設變量只可儲存 8 位元有符號整數（−128 至 127）。用數學方法交換時，第一步 x = x + y 的結果可能超出範圍，於是發生算術溢出。

−1280127

註：Python 的整數沒有大小上限，所以在 Python 中不會溢出；但很多程式語言或系統的變量大小是固定的。暫存變量方法完全沒有這個風險。
